# Austin 311

**[austin311.com](https://austin311.com)** — Live maps and trend data on what Austin's city government is (and isn't) doing.

Not a government website. Built by a concerned citizen using publicly available open data.

## Data sources

- **[Austin Open311 API](https://311.austintexas.gov/open311/v2)** — all 311 service requests
- **[Austin Open Data Portal](https://data.austintexas.gov)** — APD crime, crashes, restaurant inspections, court data, water quality, childcare, MetroBike
- **[Texas Open Data Portal](https://data.texas.gov)** — TABC mixed beverage sales (bar of the month)

All data is publicly available. Get your own API key at [data.austintexas.gov](https://data.austintexas.gov).

## How it works

Static HTML maps generated by Python scripts, deployed to GitHub Pages at `docs/`. GitHub Actions workflows regenerate the maps on a weekly schedule and commit the output back to the repo.

A few pages query pre-computed JSON snapshots in `docs/querystore/` client-side; those are refreshed by the same weekly run, and the API in front of them is a small Cloudflare Worker in `workers/query-gateway/`.

```
scripts/generate_map.py <category>   # regenerate any map locally
python scripts/generate_map.py crime-trends
```

### Local setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env   # add AUSTINAPIKEY (optional, for API rate limits)
python scripts/generate_map.py graffiti
```

Generated maps are written to `docs/<category>/index.html`.

There is no test suite; check a change with `.venv/bin/python -m compileall -q .` and by regenerating the affected page. `search-311` is the one console script that works (`search-311 --help` to browse service codes).

### Environment variables

| Variable | Required | Description |
|----------|----------|-------------|
| `AUSTINAPIKEY` | No | Austin Open Data app token — used for **both** Socrata (crime, budget, court, restaurant, water, pulse) and Open311 requests. Without it, requests are slower and more likely to be throttled |
| `CLOUDFLARE_API_TOKEN` | CI only | Deploys the query worker (`workers/query-gateway/`); not needed for local page generation |
